# Vehicle listing publication workflow

Stage 4 includes listing-prep.html, a browser-only tool for preparing JSON drafts. It does not authenticate users, store submissions, or publish inventory.

1. Obtain the seller's permission to publish accurate vehicle information and photos.
2. Prepare a draft in listing-prep.html. Do not enter seller phone numbers, private addresses, identity documents, registration certificate numbers or other sensitive personal information.
3. Download the draft JSON and review the details and photo rights.
4. Independently verify vehicle claims before using any verified/inspected label. Never claim a sale, price, inspection or availability without confirmation.
5. A later stage can import approved drafts into a curated listings data file, subject to review.
6. Public enquiries should use the business number +91 9340196039. Never put secrets, API keys or private customer information in this public repository.

Security: robots noindex is not access control. This tool is publicly reachable if the site is deployed. A production admin dashboard will require real authentication, authorization and server-side validation.
